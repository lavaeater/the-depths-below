# Keybindings

## Submarine Controls (held)

| Key | Action |
|-----|--------|
| W | Throttle forward |
| S | Throttle reverse |
| A | Strafe left |
| D | Strafe right |
| Up arrow | Ascend |
| Down arrow | Descend |
| Left arrow | Yaw left |
| Right arrow | Yaw right |

## Debug: Marching Cube Builder (one-shot)

| Key | Action |
|-----|--------|
| U | Move view in |
| J | Move view out |
| H | Move view left |
| L | Move view right |
| Y | Move view up |
| I | Move view down |
| M | Index up |
| N | Index down |
| Space | Update model |
| P | Toggle points |
| B | Toggle started |
